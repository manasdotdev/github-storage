## what is a container?

they are not like one massive superpowered single concept, instead it's like three features ducked together which forms or can be considered as a container.

- linux jail
- cgroups
- namespaces

### Bare metal - literally one giant machine

### VM - you are just kinda burning some x amount of resources just for the sake of seperation. E.g: running 17 instances of arch on a single machine, each with its own kernel and resources. This is resource intensive(not that much, but it's also still nothing ) and not efficient.
